Exercise 19.1
Subtask 1
Implement in C# a class for this UML diagram.
___________________________________
|            Person               |
|---------------------------------|
| - name: String                  |
| - age: int                      |
| - cpr: String                   |
|---------------------------------|
| + GetName(): String             |
| + GetAge(): int                 |
| + GetCpr(): String              |
| + ToString(): String            |
-----------------------------------
Note: The cpr field refers to a Danish social security number format called CPR.
Hint: When the ToString method is defined in the UML class, then you have to override the
method and give it a meaningful implementation.

    This wants a class (Im assuming public), that has 3 private properties, name (string),  age (int) and cpr (string). Other than that, it wants 4 public methods, GetName which returns a string, GetAge which returns an integer, GetCpr which returns a string and ToString which returns all properties in a string.

Subtask 2
Make a List that contains 5 Person objects. You decide the attribute values. One person must
have the CPR number 010101-0101.
    people.Add(new Person("John Doe", 32, "101010-1010"));
    people.Add(new Person("Jane Doe", 31, "010101-0101"));
    people.Add(new Person("Mr. Meow", 4, "690420-6769"));
    people.Add(new Person("idk", 100, "102223-4000"));
    people.Add(new Person("idk v2", 50, "322342-6000"));

Subtask 3
Loop through your List object and find the person with the CPR number 010101-0101 by
calling the method GetCpr on each object.
Print the result of an (explicit or implicit) call to the ToString method on this object.
    foreach (Person i in people) {
        if (i.GetCpr() == "010101-0101") {
            Console.WriteLine("Found in list (3 lines): "+i.ToString());
        }
    }

Subtask 4
Create a Dictionary<string, Person> map and add the Person objects to this map that you
previously added to the List object in subtask 2. Use the CPR number as the key.
    Dictionary<string, Person> map = new Dictionary<string, Person>();

    foreach (Person i in people) {
        map.Add(i.GetCpr(), i);
    }

Subtask 5
Find the person with the CPR number 010101-0101 in the Dictionary object and print the
value returned from a call to the ToString method on this object.
    Console.WriteLine("Found in dictionary (1 line of code): "+map["010101-0101"].ToString());
